# Requirement Analysis

## Functional Requirements

### User Module
- User registration
- User login
- Search available cabs
- Book cab
- View booking history

### Admin Module
- Manage users
- Manage vehicles
- Manage bookings

## Non Functional Requirements
- Security
- Performance
- Reliability
- User friendly interface

## Technology Requirements

Frontend:
- React.js

Backend:
- Node.js
- Express.js

Database:
- MongoDB
