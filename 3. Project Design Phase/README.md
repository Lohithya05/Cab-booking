# Project Design Phase

## System Architecture

The Cab Booking System follows a three-layer architecture:

1. Client Layer
   - React.js frontend

2. API Layer
   - Express.js REST APIs

3. Database Layer
   - MongoDB


## Database Design

Collections:
- Users
- Admins
- Cars
- Bookings
